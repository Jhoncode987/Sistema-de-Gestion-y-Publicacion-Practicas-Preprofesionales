# Historias de Usuario

| Código y Título | Descripción de la Historia de Usuario |
|---|---|
| **HU-01: Registro de Empresa** | Como Empresa, quiero registrarme en el sistema para poder publicar ofertas de prácticas preprofesionales. |
| **HU-02: Validación de Entidades** | Como Coordinador de prácticas, quiero aprobar o rechazar el registro de una empresa y sus ofertas para asegurar que cumplan los estándares de la universidad antes de ser visibles. |
| **HU-03: Publicación de Oferta** | Como Empresa, quiero publicar ofertas indicando carrera, ciclo mínimo, modalidad, vacantes y fecha límite para encontrar a los candidatos adecuados. |
| **HU-04: Búsqueda y Filtrado** | Como Estudiante, quiero filtrar y ver únicamente las ofertas correspondientes a mi carrera y ciclo para ahorrar tiempo en mi búsqueda. |
| **HU-05: Postulación Automática** | Como Estudiante, quiero postular a una oferta para que el sistema valide automáticamente si cumplo con los créditos y ciclo requeridos antes de aceptar mi solicitud. |
| **HU-06: Seguimiento de Convenio** | Como Coordinador de prácticas, quiero hacer seguimiento a las postulaciones, convenios y prácticas de los estudiantes de mi ámbito, con estados separados para candidatura, documento de convenio y avance de la práctica para llevar un control institucional trazable. |
| **HU-07: Notificaciones** | Como Estudiante, quiero recibir notificaciones cuando se publiquen nuevas ofertas de mi carrera o cambie el estado de mi postulación para estar informado oportunamente. |
| **HU-08: Evaluación de Postulantes** | Como Empresa, quiero consultar y evaluar candidatos de mis propias ofertas y seleccionar o rechazar sus postulaciones, sin acceder a candidatos de otras empresas. |
| **HU-09: Reportes de Oficina** | Como personal autorizado de la Oficina de Prácticas, quiero consultar dashboard y exportar PDF/Excel por periodo y carrera respetando mis permisos y filtros. |

La aprobación de empresa y oferta son operaciones separadas. Seleccionar no activa un convenio ni inicia una práctica. Los avisos de HU-07 son internos por destinatario y con estado de lectura.
