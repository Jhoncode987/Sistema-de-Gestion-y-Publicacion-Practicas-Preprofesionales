# Diagramas C4

En esta carpeta se documentarán los cuatro niveles del modelo C4:

1. **C1 — Contexto:** usuarios, sistema y sistemas externos.
2. **C2 — Contenedores:** aplicaciones, servicios ejecutables y almacenes de datos.
3. **C3 — Componentes:** responsabilidades y relaciones internas de un contenedor.
4. **C4 — Código:** clases e interfaces relevantes de un componente.

Los diagramas se añadirán progresivamente durante la Guía 4. Los nombres, límites y relaciones deben ser coherentes entre niveles.
