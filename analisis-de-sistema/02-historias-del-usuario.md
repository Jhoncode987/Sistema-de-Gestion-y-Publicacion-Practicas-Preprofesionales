# Historias de Usuario

| Código y Título | Descripción de la Historia de Usuario |
|---|---|
| **HU-01: Registro de Empresa** | Como Empresa, quiero registrarme en el sistema para poder publicar ofertas de prácticas preprofesionales[cite: 24]. |
| **HU-02: Validación de Entidades** | Como Coordinador de prácticas, quiero aprobar o rechazar el registro de una empresa y sus ofertas para asegurar que cumplan los estándares de la universidad antes de ser visibles[cite: 24]. |
| **HU-03: Publicación de Oferta** | Como Empresa, quiero publicar ofertas indicando carrera, ciclo mínimo, modalidad, vacantes y fecha límite para encontrar a los candidatos adecuados[cite: 24]. |
| **HU-04: Búsqueda y Filtrado** | Como Estudiante, quiero filtrar y ver únicamente las ofertas correspondientes a mi carrera y ciclo para ahorrar tiempo en mi búsqueda[cite: 24]. |
| **HU-05: Postulación Automática** | Como Estudiante, quiero postular a una oferta para que el sistema valide automáticamente si cumplo con los créditos y ciclo requeridos antes de aceptar mi solicitud[cite: 24]. |
| **HU-06: Seguimiento de Convenio** | Como Coordinador de prácticas, quiero hacer seguimiento al estado del convenio de cada estudiante (postulado, seleccionado, en curso, culminado) para llevar un control institucional trazable[cite: 24]. |
| **HU-07: Notificaciones** | Como Estudiante, quiero recibir notificaciones cuando se publiquen nuevas ofertas de mi carrera o cambie el estado de mi postulación para estar informado oportunamente[cite: 24, 25]. |
