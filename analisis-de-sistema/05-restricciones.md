# Restricciones

| Restricción | Descripción |
|---|---|
| **Limitaciones Financieras/Pagos** | El sistema no contempla ni gestiona pagos, transacciones monetarias, ni subvenciones económicas asociadas a las prácticas. |
| **Independencia del Core Académico** | La solución no reemplaza al sistema académico institucional (matrícula, notas, campus virtual); solo se integra con él (ej. SIGA) para consultar datos de elegibilidad del alumno. |
| **Ámbito Institucional** | El alcance está limitado a gestionar las prácticas de la UNSCH; no incluye la gestión de prácticas fuera de este ámbito ni la evaluación curricular o certificación oficial (que recae en cada área académica). |
| **Despliegue e Infraestructura** | Dado que no maneja información financiera crítica, el sistema debe ser capaz de desplegarse en infraestructura propia de la universidad o en nubes de nivel académico/gratuito para mitigar costos. |
